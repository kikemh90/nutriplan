## Importante para instalaciones existentes
NutriPlan guarda el catálogo instalado en `localStorage`. Por eso desplegar esta
versión en GitHub no sustituye automáticamente un catálogo ya instalado.
Después del despliegue hay que importar manualmente el archivo:
`NutriPlan_catalogo_2026.09.10-v3.json`
desde Ajustes -> Importar catálogo.

La importación conserva el histórico según el modelo de snapshots y refresca
las semanas actual/futuras con las versiones nuevas.
